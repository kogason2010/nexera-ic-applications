# Nexera IC Applications: unofficial interactive showcase

**Live site:** https://kogason2010.github.io/nexera-ic-applications/

Published Nexera IC applications (EPA 300.1 Part A and B, ASTM D6919-17 cations, dual channel) told
through procedurally built 3D ions, with an interactive ion atlas and a methods table.

> Independent, unofficial project. Not affiliated with, sponsored or endorsed by Shimadzu Corporation.

- **Repository root:** the built static site, served by GitHub Pages.
- **`source/`:** the React, three.js and GSAP project. See `source/README.md`.
- Companion site: https://kogason2010.github.io/nexera-ic/
