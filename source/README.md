# Nexera IC Applications: unofficial interactive showcase

**Live:** https://kogason2010.github.io/nexera-ic-applications/

Published Nexera IC applications told through procedurally built 3D ions: a single ion stage re-forms
for each chapter (EPA 300.1 Part A anions, Part B disinfection by-products, ASTM D6919-17 cations,
dual channel), plus an interactive ion atlas and a methods table. Same stack as the main showcase
(React, TypeScript, Vite, three.js, @react-three/fiber, GSAP, Lenis).

> Independent, unofficial project. Not affiliated with, sponsored or endorsed by Shimadzu Corporation.
> Molecular models are illustrative (textbook bond lengths); chromatograms are redrawn from the cited
> application notes. Part B retention times are read from its Fig. 3 and are approximate.
